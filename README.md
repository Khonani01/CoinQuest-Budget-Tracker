## Project Overview
CoinQuest is a gamified personal finance app that turns budgeting into a "quest." By logging expenses and meeting goals, users earn XP and badges, solving the engagement gap found in traditional apps like YNAB and Goodbudget.

## Tech Stack
* **Language:** Kotlin
* **Database:** RoomDB / SQLite (Offline Persistence)
* **Architecture:** MVC (Model-View-Controller)
* **CI/CD:** GitHub Actions (Automated Android Builds)
* **Visuals:** MPAndroidChart
